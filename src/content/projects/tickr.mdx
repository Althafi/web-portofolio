## Problem

Food, cosmetics, and medicine quietly expire at the back of the fridge or cabinet. Most people only notice once it is already wasted.

## Solution

Tickr lets you log an item with its expiry date, photo, and category, then sends local reminders before it expires. Everything is stored on the device, so there is no account, login, or server to depend on. Barcode lookup is the only feature that uses the internet, and it is optional.

## Key features

- Home overview of items expiring soon, grouped by category, with a consumption donut and a waste trend
- Add items with name, category, quantity, unit, expiry date, and a photo from the camera or gallery
- Search and filter the expiry list by category, urgency, and time range
- Insights calculated on the device: savings score, statistics, streaks, habits, tips, and achievements
- Light, dark, and system themes, in Indonesian and English
- Export all items and photos to one JSON file, and restore them from it

## Under the hood

Clean Architecture with an MVI presentation layer. Business logic, ViewModels, and UI all live in `commonMain`; platform code is limited to the database driver, photo storage, notifications, camera, and barcode scanner. Repositories expose `Flow` from SQLDelight, so every screen updates by itself when the data changes, and rules such as Insights and reminder scheduling are pure functions that are easy to test.

## Status

In active development. The Android app is the main target; some iOS pieces (photo picker, camera, barcode scanner) are still stubs.
