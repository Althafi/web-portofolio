## Problem

Cleaning staff in the field need one place to see today's jobs, update their progress, and report what was actually done, instead of juggling chats and paper notes.

## Solution

The app talks to a Laravel REST API (Sanctum token auth, deployed on Railway). Staff see their jobs per day, open a job for customer info, contact, pricing, photos, and a Maps or WhatsApp shortcut, and move it through the status flow: assigned, in progress, awaiting verification, invoice created, completed.

## Key features

- Login with a token kept in secure storage, and automatic session restore on launch
- Job detail sheet with customer info, pricing breakdown, invoice summary, photos, and notes
- Final items report with an optional fixed discount and down payment, editable while the job is still open
- Hourly jobs with planned versus actual duration, cleaner count, and notes
- Profile editing with a photo from the camera or gallery, and a secure change-password flow
- FCM push notifications, an in-app notification screen, and an offline banner

## Under the hood

Clean-Architecture-inspired layers (`domain`, `data`, `presentation`, `core`). Auth state is a sealed class that drives the whole UI tree, repositories return a `Result<T>` so no raw exceptions cross layers, and each date has its own auto-disposing Riverpod provider.

## Status

A portfolio project built against a real backend, still under active development.
